# Band Name Generator

## Description
A beginner Python project that generates a band name based on the user's city and pet names.

## Features
- Gets the user's city name
- Gets the user's pet name
- Combines both names to generate a band name

## Technologies
- Python 3

## How It Works
1. The user enters the city name.
2. The user enters the pet name.
3. The program combines both names and generates the band name.

## Example
```text
Welcome to The Band Name Generator.
What's the name of the city you grew up in? Baghdad
What's your pet's name? Bear
Your band name could be Baghdad Bear
```
